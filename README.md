Madhav E-Commerce Sales Dashboard (Power BI)

📊 Project Overview
This project is a Power BI dashboard created for Madhav E-Commerce to analyze sales performance.  
It provides insights into revenue, profit, product categories, customer trends, and payment modes.

🛠 Tools & Technologies
- Microsoft Power BI
- Data Modeling (Orders & Details tables)
- DAX Measures
- Data Visualization (Charts, Donut, Bar Graphs)

🔑 Key Insights
- Total Sales Amount: 17K  
- Total Profit: 1571  
- Total Quantity Sold: 216  
- Clothing category contributed ~70% of sales.  
- COD was the most used payment mode (~41%).  
- Phones generated the highest profit (~1200).  
- Negative profits observed in some Saree orders (loss-making trend).  

📂 Dataset
- Orders Table: Order ID, Customer Name, City, State, Order Date  
- Details Table: Amount, Profit, Quantity, Category, Sub-Category, Payment Mode  


🎯 Purpose
This dashboard demonstrates **data analytics skills** including:
- Data cleaning & modeling  
- Business insights generation  
- Visualization storytelling  

📈 Business Impact
Helps Madhav E-Commerce track:
- Profitable vs loss-making products  
- Customer purchase behavior  
- Payment mode preferences  
- State-wise performance
